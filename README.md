# Specimen Studio

A free figure editor for scientific figures and graphical abstracts, with its own icon library.

**Open it:** https://specimen-studio.github.io/

- Everything runs in your browser. Your figures are saved in your own browser (or to your computer with *Save to computer*); nothing is uploaded.
- Icon library: CC BY 4.0 (see `library/LICENSE.txt`). In a figure legend, this is enough:
  *Figure created by the authors using Specimen Studio. Icons were generated from human prompts using ChatGPT (OpenAI) and Claude (Anthropic).*
- Missing an icon? Use **Request an icon** in the gallery.

Concept and design: N. López-Alcántara. Built with Claude (Anthropic).
